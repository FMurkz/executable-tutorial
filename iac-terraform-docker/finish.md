### Reflecting upon the tutorial and Terraform
In this tutorial we have learned how to use Terraform in an effective manner and why its a good practice to use it for infrastructure as code. We have seen that its beneficial for reproducability, quick changes, infrastructure where many work on the same project, and for detecting drift in the system. However, sometimes Terraform can be a little bit overkill for small projects, and in those cases it might be better to use a simpler tool like Docker Compose. The documentation for Docker Compose can be found [here](https://docs.docker.com/compose/). 

But here we have seen that Terraform is a great tool for regularly creating or managing infrastrucuture, especially for devlopers and DevOps engineers.
